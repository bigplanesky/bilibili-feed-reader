# B站动态已读助手 1.0.1

## 安装（只需一次）

1. 在 Edge 地址栏输入 `edge://extensions`，回车。
2. 打开页面上的「开发人员模式」。
3. 点击「加载解压缩的扩展」。
4. 选择解压后直接包含 `manifest.json` 的文件夹。从 GitHub「Code → Download ZIP」下载后通常叫 **bilibili-feed-reader-main**。不要选择 ZIP 文件、上一级文件夹或 `docs` 子目录。
5. 回到 `https://t.bilibili.com/`，刷新页面。右侧会出现「动态已读助手」，每条动态上方会出现状态按钮。

下载方式：在 [项目仓库](https://github.com/bigplanesky/bilibili-feed-reader) 点击「Code → Download ZIP」，或克隆仓库。使用 ZIP 时先完整解压，再选择包含 `manifest.json` 的文件夹。保留这个文件夹，Edge 会继续从这里加载扩展。普通使用不需要安装开发工具或构建。

## 日常使用

- 点击动态卡片**底部的评论按钮**，评论区展开并显示评论界面或空评论提示后，自动记为已读。
- 从动态卡片点击视频封面／标题、动态标题／正文／时间进入详情时，也会记为已读；视频链接支持 Ctrl 点击和鼠标中键。
- 点赞、转发、滚动浏览、作者主页、话题、图片预览和「展开」正文不会记为已读。右键菜单中选择「在新标签页打开」暂不自动识别，可用 Ctrl 点击或中键代替。
- 每条动态的「标为已读／改为未读」按钮，可以手动纠正状态。
- 勾选「隐藏已读」，把此前看过的动态隐藏。取消勾选可恢复显示。
- 刚刚在本次页面中读过的动态继续保留，收起评论也不会立即消失。刷新、重新进入页面或点击「重新应用筛选」后，才按已读状态隐藏。
- 时间范围默认最近 **30 天**，可选最近 7 天、30 天、90 天或全部；开关和时间范围会记住。
- 筛选隐藏了连续多屏内容时，助手会尝试继续触发 B 站原来的加载。每轮最多补载 10 批，之后点击「继续查找未读」。加载失败时点击「重试加载」。
- 工具栏右上角「−」可收起面板，「+」可展开。
- 卡片状态按钮放在作者栏下方独立的一行，避免挤压 B 站固定高度的昵称／时间区域。

## 时间和统计

- 超出时间范围的动态只是隐藏，并没有被记成已读。
- 转发使用转发动态自身的时间和 ID，不会同时将原动态标成已读。
- 统计只针对**已经加载到页面里的动态**，不是全部未读总数。
- 单条旧置顶不作为时间边界。新加载的一整批普通动态都超出时间范围时暂停查找；遇到特殊乱序仍可点击继续。
- 无法取得可靠 ID 或发布时间时，动态保留可见，避免误隐藏。没有可靠 ID 的卡片不能自动保存已读；缺少时间的卡片在「全部」范围下仍可按已读筛选。
- 日期只能精确到一天时采用当天结束时间，避免在筛选边界提前隐藏；组件能提供准确发布时间时优先使用准确时间。

## 数据和更新

数据保存在当前 Edge 配置的扩展本地存储中，不上传服务器，也不读取 Cookie、密码或视频观看记录。记录从启用助手开始，无法追溯安装之前看过的动态。

本版按单个日常 B 站账号设计。同一个 Edge 配置切换 B 站账号时，已读记录仍共用；不同 Edge 配置、其他电脑和手机之间不自动同步。

更新扩展时，保留原文件夹和已经安装的扩展，在原目录更新文件，然后到 `edge://extensions` 点击该扩展的重新加载，再刷新动态页。不要用卸载重装作为常规更新方式。

1.0.1 沿用原存储格式和权限。若从 Git 安装，可在原目录执行 `git pull` 更新，再重新加载扩展与动态页。不要为了切换源码目录而卸载重装。

## 遇到异常

- **没有面板**：确认当前网址是 `https://t.bilibili.com/` 动态列表，扩展已启用，然后刷新。独立动态详情页不显示筛选面板。
- **有「无法识别此动态」**：该卡片会保留可见。可先继续使用 B 站；页面结构变化需要更新适配器。
- **评论打不开或出现错误**：不会记为已读。可以收起后重新点开，也可手动标记。
- **评论长时间仍在加载**：自动检测最多等待 30 秒。之后可重新点开评论或手动标记。
- **加载没有进展**：点击重试；仍无进展时，关闭「隐藏已读」、选择「全部」，手动滚动检查 B 站页面是否正常。
- **保存失败**：面板会显示提示，当前卡片会撤销尚未保存成功的状态；刷新扩展和页面后重试。

## 安装后快速验收

1. 找一条未读动态，点击底部评论，确认出现「已读」。
2. 勾选「隐藏已读」，再点击「重新应用筛选」，确认刚才的记录被隐藏。
3. 在隐藏模式下，再展开另一条未读动态的评论，确认它标成已读但仍留在页面中。
4. 收起评论，确认它仍保留；点击「重新应用筛选」，确认它隐藏。
5. 刷新页面，确认隐藏开关和记录仍保留。
6. 取消隐藏，将一条记录改回未读，再开启隐藏，确认它仍可见。

验证状态见同目录的《验证结果.md》。
